# training-app

Personal training and food app. Phone-first, works offline, add it to your home screen.

- Program content: `data/program.json` (sessions, food, rules) and `data/howto.json` (steps, photos, videos).
- Everything you log stays on the phone (browser storage). Use Body → Backup now and then.
- Demo photos: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).
